## Selected Case Studies

### 1. Case Study 6: Online Shopping Website

**Description:**

This website represents an online shopping platform where users can view product categories, product details, prices, discounts, and ratings.

**Features:**
- Product categories
- Product cards with prices and discounts
- Product descriptions and ratings
- Navigation menu
- Responsive webpage design

**Files:**
- `index.html`
- `style.css`

### 2. Case Study 7: Electronics Store Website

**Description:**

This website represents an electronics store where users can view electronic products, specifications, prices, and discounts.

**Features:**
- Electronic product cards
- Product specifications
- Prices and discounts
- Product comparison table
- Responsive webpage design

**Files:**
- `index.html`
- `style.css`

### 3. Case Study 17: Tourism and Heritage Information Website

**Description:**

This website provides information about famous Indian heritage places, Indian culture, festivals, cuisine, and travel tips.

**Features:**
- Information about historical places
- Heritage destination cards
- Indian culture and festivals
- Indian cuisine information
- Travel tips
- Responsive webpage design

**Files:**
- `index.html`
- `style.css`

## Technologies Used

- **HTML5:** Used to create the structure of webpages.
- **CSS3:** Used to style webpages and arrange content.
- **Flexbox:** Used to arrange product and destination cards.
- **Media Queries:** Used to make webpages responsive on different screen sizes.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the required case study folder.
4. Double-click `index.html` to open the website in a web browser.
5. Repeat the process for the other two websites.
